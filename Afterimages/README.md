Cursor Drift Trail / Roaring Knight Afterimages

Run CursorDriftTrail.exe to start the effect. The app sits in the notification
area near the clock. Right-click its icon to pause or resume the trail, open
Settings, or exit

The app copies the cursor image Windows is currently showing, including a
custom cursor, and scales copies to Windows' cursor dimensions or its larger
configured cursor base size. In settings, change the maximum number of trail
copies, their lifetime (down to 0.01 seconds), spawn interval, etc. New
translucent copies drift opposite the latest cursor movement and fade. If the mouse stops, new copies keep appearing
and drift along the last precise heading.

For the Roaring Knight mouse, simply press Windows, search Mouse Settings, click "additional mouse options" in the corner, go to Pointers, select "Normal Select", then Browse, find the Roaring Knight .cur files in this folder, and select which one you want for your cursor's normal select. Repeat for all the other variants, and optionally save this scheme.
